# Git

- Never commit without asking. Before every commit, show me the files and the exact commit message, and wait for my approval.
- Every project is a git repo from the start (`git init` before `openspec init`).
- Commit after each logical step. Do not mix unrelated changes in one commit.
- Use Conventional Commits:
  - `feat:` new functionality
  - `fix:` bug fix
  - `chore:` setup, configuration, tooling
  - `docs:` documentation and specs
  - `refactor:`, `test:` as usual
- Commit the AI tool files generated by `openspec init`; they are part of the project.
- Never commit secrets (`.env`, keys, credentials). Add them to `.gitignore`.
- `graphify-out/` is always in `.gitignore`.
- Every repo has a complete `.gitignore` in its first commit: OS files, IDE and editor files, build output, dependencies, secrets and local config, logs, and tool output.
