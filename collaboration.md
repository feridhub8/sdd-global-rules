# Collaboration

- I am learning by doing and type most commands myself.
- Do not run commands or create/change files unless I explicitly ask. Otherwise, explain the next step, give the exact command, and say what it does.
- Before proposing next steps, check the current state (`ls`, `git status`, file contents). I often run commands without reporting back.
- Never commit without my approval (see [git.md](git.md)).
- Ask before decisions that are mine to make (naming, architecture, tools). Give a recommendation with the reason.
- Reply in Azerbaijani. Code, commit messages, and rule files stay in English.
